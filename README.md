# DoctorIA Medical Solutions — Landing Page

Marketing site for DoctorIA, an AI-powered clinical intelligence platform
covering the full cycle of care (prevention, diagnosis, treatment) across
oncology, sports medicine, and dentistry.

Built with React + TypeScript + Vite + Tailwind CSS v4.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Project structure

- `src/components/` — landing page sections (Hero, Products, Architecture, Market, Moat, Roadmap, CTA, Footer, Navbar)
- `public/images/` — brand assets (logo mark/wordmark, pillar icons)
- `src/index.css` — Tailwind theme tokens (brand colors, fonts, animations)

This is the marketing landing page only. Product features (auth, dashboards,
clinical modules, etc.) will be built on top of this foundation.
